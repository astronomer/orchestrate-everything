# Product requests

## Logging a request

Customer requests for new products, sizes, or features are logged with a PR id
and a vote count. Support tells the customer the request is logged and adds
their note to it.

## Release dates

Support never gives a release date for a request whose roadmap commitment is
none, however many votes it has. Saying that something ships next quarter when
nothing is committed is the most common cause of a reopened ticket.
