# Returns and cancellations

## Cancelling before dispatch

An order can be cancelled any time before its dispatch date. When the order
record shows the cancellation was accepted, support confirms in writing that the
authorisation is released and that the amount will not be charged. Naming the
amount and the order id is required.

## Returns after delivery

Delivered orders can be returned within 30 standard days. A return is a
different process from a cancellation, and support does not answer a
cancellation request with the returns policy.
